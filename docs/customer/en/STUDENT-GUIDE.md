# Hlasuj! by MiloslavHub — student guide

Updated 8 October 2026. These steps describe the established live voting flow. English documentation does not mean that every installed version has an English interface; the expanded interface belongs to unreleased development.

## Join the lesson

Scan the QR code shown by your teacher or open the joining link in a browser. You can use a phone, tablet or computer. You do not need to install an app or create a student account. Keep the same browser during the lesson because it holds your technical participant identity.

Choose a nickname if the current activity asks for one. Use a nickname suitable for the class and avoid including unnecessary personal information. The teacher controls live voting; opening or refreshing the link does not start the question.

## Answer

Wait until the teacher opens the question. Read the options, select your answer and check the submission confirmation. A quiz may have a time limit and scoring. A poll asks for opinions and has no correct answer. Follow the settings of the actual installation; the development changes to neutral poll scoring are documented separately.

Only one accepted vote is allowed per participant and voting session. Refreshing, using a second tab or clearing browser storage is not a supported way to change an accepted answer. A repeated question is a new session controlled by the teacher.

## View results

Results become available according to the activity settings. Correctness and any configured explanation follow the closed-voting rules. Some result links are public; do not treat a nickname as confidential merely because no account is required.

The Hall of Fame offers its own publication choice: show a nickname, appear anonymously or skip publication. This choice does not control every other result display. Read the installation's privacy information and contact its operator for questions about stored data or deletion.

## If something goes wrong

- **Waiting for the teacher:** keep the page open and ask whether voting has started.
- **Voting closed:** ask the teacher whether a new session will be opened; late votes are rejected.
- **Already voted:** check that you are in the intended session. Repeated requests do not create extra votes.
- **Connection problem:** check connectivity, then reload the original link. Repeated clearing of browser data can create a different technical identity.
- **Demo:** fictional participants are labelled. Demo timing is automatic and differs from a teacher-controlled lesson.
