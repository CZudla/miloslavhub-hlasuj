# Produktové principy

Hlasuj! by MiloslavHub. Navrženo učitelem pro učitele.

- Učitel řídí běžnou výuku. Studentský odkaz slouží k připojení.
- Student nepotřebuje účet ani instalaci a může použít telefon, tablet nebo počítač.
- Otázky a odkazy musí být dlouhodobě použitelné. Zachovat kompatibilitu existujících QR.
- Domácí úkol je samostatný způsob použití otázky či sady: „Odevzdat do“, pokusy a srozumitelná zpětná vazba. Nepřejmenovat neúplnou technickou funkci na hotový úkol.
- Nové funkce musí mít vymáhaná oprávnění, přenositelnost obsahu, privacy pravidla a jazyk UI oddělený od obsahu.
- Demo může postupovat automaticky; fiktivní respondenti jsou vždy označeni.
- Nepropagovat roadmapu jako dodanou funkci. Úspěch se ověřuje skutečným použitím učitele.
